# Project Log

This folder contains the chronological journal of meaningful decisions, features, and changes made during the development of this e-commerce platform.

These entries are the **source material** for project reports, retrospectives, and academic deliverables. They capture the **why** behind the code — context, trade-offs, alternatives rejected — that the codebase alone cannot express.

## Conventions

- One Markdown file per entry, named `YYYY-MM-DD-short-slug.md`
- Multiple entries per day are allowed (use distinct slugs)
- Written in English
- See [CLAUDE.md](../CLAUDE.md#project-journaling--mandatory) at the repo root for the full template and triggering rules
